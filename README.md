# fs-backend-windows

Windows mechanisms for [`cl-stack-pathlib`](https://github.com/egao1980/cl-stack-pathlib):
the `:rdcw` change journal (`ReadDirectoryChangesW`) behind `fs-watch` (R4b-3, brief in
[cl-stack/docs/capabilities](https://github.com/egao1980/cl-stack/tree/main/docs/capabilities)).
